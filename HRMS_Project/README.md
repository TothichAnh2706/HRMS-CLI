# HRMS – Hệ Thống Quản Lý Nhân Sự
**Human Resource Management System** | BTL OOP C++ – Nhóm 4 Người

## Cách Build & Chạy
```bat
build.bat        # Build
hrms.exe         # Chạy (từ thư mục này)
```

## Tính Năng
- **TV1:** Quản lý nhân viên, phòng ban, chức vụ, xác thực
- **TV2:** Chấm công (check-in/out), nghỉ phép, báo cáo
- **TV3:** Tính lương (thuế TNCN lũy tiến), hợp đồng, khen thưởng/kỷ luật
- **TV4:** Tuyển dụng, đào tạo, báo cáo thống kê, feedback
